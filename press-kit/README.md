# Press kit — Trailer Roulette

Drop-in materials for press coverage, Product Hunt, Reddit, and friend-of-friend outreach.

## Quick facts (for the "About" line in any pitch)
- **What**: Trailer Roulette is a movie-discovery slot machine for iPhone. Spin trailers like channels, save what you love, swipe past what you don't.
- **Who**: Charlie Cresci, solo indie developer
- **Where**: iOS App Store (US, then global)
- **Price**: Free, no ads, no accounts
- **Tech**: Capacitor + React; trailers play via YouTube's official embedded player inside Apple's SFSafariViewController
- **Privacy**: Data Not Collected (Apple's strictest nutrition label); no backend, no tracking

## Approved phrases (use these)
- "Personalized movie discovery"
- "Curated trailer shuffle"
- "Local-first, on-device taste profile"
- "Privacy-respecting"
- "AirPlay support"

## Phrases to avoid
- "Stream movies for free" — implies licensed streaming
- "YouTube alternative" / "YouTube wrapper" — invites the wrong category
- "Track what you watch" — we don't track anything
- Competitor names (JustWatch, Reelgood, MovieFone) — don't compare; differentiate
