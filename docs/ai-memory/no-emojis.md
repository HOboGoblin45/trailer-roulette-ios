Charlie asked (2026-06-29) for NO emojis whatsoever — in the Trailer Roulette app's UI and in responses.

**Why:** Personal preference; emojis felt off for his app and conversation tone.

**How to apply:** Use plain text and clean typographic/SVG glyphs (close, play, arrows, checkmarks are fine) instead of emoji. When building UI, never put emoji in labels, buttons, headings, or placeholders — use text, an SVG icon, or a letter/monogram (see FunSheet's and TheaterSheet's monogram tiles). Keep chat replies and docs emoji-free.
