# What's New — v1.8.0

For App Store Connect "What's New" field on the v1.8.0 update submission.

## v1.8.0 (paste this)

```
Trailer Roulette is now a tour of pre-2010 cinema by default — the 70s, 80s, 90s and 2000s, the films that built modern Hollywood. Want something newer? Flip the new Era toggle to Modern any time.

Also in this update:
• Trailers play in a clean fullscreen modal inside the app instead of bouncing you to Safari.
• Trailers that publishers have blocked from embedding now skip automatically — no more error screens.
```

(415 chars.)

## Why this messaging

The lead says what changed for the user (tour of pre-2010), and the secondary
bullets cover the playback fixes. Nothing about the underlying engineering
saga (WebKit Bug 169846, the YT 153/152 errors, the proxy attempts) — App
Store readers don't care; they care about the user-visible difference.

The "Modern toggle" mention reassures users who only want recent films that
the app still serves them.
