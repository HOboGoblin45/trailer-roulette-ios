# Trailer Roulette · app/

The Capacitor + React + Vite source tree.

## Run on web (development)

```bash
cp .env.local.template .env.local
# edit .env.local and paste your TMDB v3 API key

npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:5173).

## Build for iOS (Phase 2 prerequisite: Mac + Apple Developer enrollment)

```bash
npm run build
npx cap add ios          # first time only
npx cap sync ios

# Add the AirPlay plugin and merge Info.plist additions:
# follow ./ios-native/README.md

npm run ios:open         # opens the Xcode workspace
```

Then in Xcode: select your team in **Signing & Capabilities**, hit Cmd+R.

## Live reload on a real device during dev

```bash
npx cap run ios -l --external
```

The device will load the dev server from your Mac's LAN IP. Capacitor handles the IP discovery; the device must be on the same network.

## Architecture quick map

| Module | Role |
|--------|------|
| `src/App.jsx` | screen router (shuffle / watchlist / about) |
| `src/components/TrailerRoulette.jsx` | shuffle screen — owns the queue, profile, cycle timer |
| `src/components/Player.jsx` | router → `Player.web.jsx` (iframe) or `Player.ios.jsx` (SFSafariViewController) |
| `src/components/SwipeOverlay.jsx` | gesture capture for Seen it / Skip it |
| `src/components/Watchlist.jsx` | saved trailers list |
| `src/components/Filters.jsx` | genre + decade chips, horizontal scroll on mobile |
| `src/components/UpNext.jsx` | next 5 in queue, bottom sheet on mobile |
| `src/lib/storage.js` | Capacitor Preferences ↔ localStorage abstraction |
| `src/lib/tasteProfile.js` | local affinity buckets (genre/decade/runtime) |
| `src/lib/shuffleWeighting.js` | softmax-mixed-with-uniform queue ordering |
| `src/lib/haptics.js` / `dialog.js` / `airplay.js` | Capacitor capability wrappers |
| `src/lib/tmdb.js` / `youtube.js` | external service helpers |
| `ios-native/AVRoutePlugin.swift` | custom Capacitor plugin around AVRoutePickerView |

## What's NOT in here yet (and where it goes)

- The Xcode project (`ios/`) — generated by `npx cap add ios` on the Mac
- The TMDB API key — you fill in `.env.local`
- Per-device app icons — `npx capacitor-assets generate` runs in Phase 4
- Splash storyboard — Xcode-side, also Phase 4

## Known shape constraints
- Trailer object shape is documented at the bottom of `src/lib/tmdb.js`. If you swap out TMDB, conform to that shape.
- Storage keys are enumerated in `KEYS` in `src/lib/storage.js`. Don't sprinkle string literals — extend the enum.
